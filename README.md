# 粉笔选项排除器

在粉笔网页版做题时，临时划掉不需要的选项，并为题干添加高亮、下划线或删除线。插件只改变当前页面的显示，不会选择或提交答案。

当前版本：`v1.2.0`

## 安装（Chrome / Edge）

1. 点击 GitHub 页面右上角的 `Code` → `Download ZIP`，然后解压。
2. 打开扩展管理页：Chrome 输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
5. 刷新已经打开的粉笔做题页面。

## 使用

- 点击 A/B/C/D 前面的 `×` 排除选项。
- 点击 `↶` 恢复。
- 快捷方式：按住 `Alt`（Mac 为 `Option`）点击选项。
- 选中题干中的文字后，会出现标记工具条，可选择“高亮”“下划线”或“删除线”。
- 直接点击已经标记的文字，会出现对应的“删除标记”按钮。
- 点击浏览器工具栏里的插件图标，可以暂时关闭或重新开启。

## 说明

- 排除状态和文字标记仅保存在当前页面；刷新、切换整页或重新进入题目后会重置。
- 插件只在 `fenbi.com` 域名下运行。
- 如果粉笔大幅调整页面结构，选项按钮可能暂时无法显示。

## 隐私

插件不收集、不上传任何数据。它仅申请浏览器本地设置存储权限，并且只在粉笔网站页面中运行。
